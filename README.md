# 何切る道場 - 麻雀初心者練習アプリ

麻雀のルールや牌の並べ方が分からなくても、効率の良い捨て牌が**白く光る枠**で分かる初心者向け練習アプリです。ブラウザだけで動作し、スマホでもそのまま遊べます。

## 遊べるモード

- **何切る練習モード**
  配牌から効率の良い1枚が白枠でハイライトされます。連続プレイ対応で、ツモ切りを繰り返しながらテンパイ・和了を目指せます。

- **中級者モード**
  リーチ・鳴きが入った場面を想定し、「現物」「スジ」「見えている字牌の枚数」から安全な牌を見極める練習ができます。ドラの見え枚数や親・子の立場も考慮した場況情報つき。

- **CPU対戦モード**
  弱卓・中卓・強卓の3段階からCPUの強さを選び、東1局〜東4局の全4局で対局します。ポン・チー・カン・リーチに対応し、役判定・符計算・点数計算もフルスクラッチで実装しています。

- **ルール解説・用語集**
  シャンテン数、面子・雀頭、鳴き、危険牌の読み方などを、いつでも読み返せる形でまとめています。

## 遊び方

このリポジトリを [GitHub Pages](https://pages.github.com/) で公開すると、以下のURLでそのまま遊べます(ダウンロード不要)。

```
https://<ユーザー名>.github.io/<リポジトリ名>/
```

スマホのブラウザでアクセスし、メニューから「ホーム画面に追加」を選ぶとPWA(アプリのような見た目)として利用できます。

`index.html` 単体をダウンロードして、ブラウザで直接開いて遊ぶこともできます(音声もすべて埋め込み済みです)。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体。牌画像・BGM・効果音まですべて1ファイルに埋め込み |
| `manifest.json` | PWA用の設定(アプリ名・アイコン・表示モード) |
| `sw.js` | オフラインでも開けるようにするサービスワーカー |
| `icon-192.png` / `icon-512.png` / `icon-512-maskable.png` | ホーム画面用アイコン |

## 技術メモ

- 外部ライブラリなし、素のHTML / CSS / JavaScriptのみで実装
- シャンテン数計算・面子分解・役判定(通常役〜役満)・符計算・4人打ちの進行(鳴き・リーチ・流局精算)まで自作
- CPUの打牌・鳴き・リーチ判断は強さごとに異なるロジックで動作(強卓は現物・スジによる押し引き判断つき)
- 古い(2015年頃相当の)ブラウザエンジンでの動作確認も行い、`flatMap` / `Object.values` / `??` など比較的新しいJS構文は使わず、互換性の高い書き方に統一
